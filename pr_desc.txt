💡 What: Removed redundant `aria-label="New Run"` attributes from the "New Run" buttons in `swe-ui/components/ThreadTabs.tsx`.

🎯 Why: The buttons already contain the visible text "New Run" (within `<span className="hidden sm:inline">New Run</span>`). Adding an identical `aria-label` overrides the semantic text with duplicate information for screen readers and creates unnecessary code clutter.

📸 Before/After: Visuals are unchanged. Semantic code structure is simplified.

♿ Accessibility: Improves screen reader clarity by avoiding redundant/duplicate announcements of the button's action text.
